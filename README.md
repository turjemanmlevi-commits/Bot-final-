# Bot de entradas · Real Madrid Femenino

Prueba completa en un clic: **▶ Hacer prueba** en el panel local → el bot abre la web de entradas del Real Madrid (tickets.realmadrid.com, plataforma Onebox), entra en el próximo partido del femenino a la venta, elige las entradas con tus requisitos (cantidad, zona, asientos seguidos, precio máximo), las mete en el carrito y te avisa por **Telegram** para que decidas. **El pago siempre lo haces tú.**

Instalación y uso: [prueba/README.md](prueba/README.md).

- **Windows** (PowerShell): `irm https://raw.githubusercontent.com/turjemanmlevi-commits/Bot-final-/claude/confident-planck-41m20b/instalar.ps1 | iex`
- **Mac/Linux**: `curl -fsSL https://raw.githubusercontent.com/turjemanmlevi-commits/Bot-final-/claude/confident-planck-41m20b/instalar.sh | bash`

Comprobación automática sin tocar la web real: `npm run prueba:smoke`.
